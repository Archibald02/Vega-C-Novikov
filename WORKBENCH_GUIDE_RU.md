# Quant Price Live 6: исследования, устойчивость и новые свечи

Учебное приложение C++17 / Qt 6 для Windows 10/11 x64. Основной источник — официальный публичный MOEX ISS, без регистрации. Данные задержаны. Реальные торговые поручения не отправляются. ДЕМО содержит только синтетические цены.

## Запуск и маршрут исследования

1. Распакуйте **весь** Windows ZIP из успешного GitHub Actions в отдельную папку. Запустите `START_QUANT_PRICE_LIVE.cmd` или `quant_price_live.exe`. Скрипт проверяет наличие EXE, Qt, плагина Windows и базового VC++ Runtime. Для отсутствующих MSVCP140/VCRUNTIME140 нужен [официальный VC++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). Скрипт ничего не устанавливает автоматически.
2. Откройте «Лаборатория». Введите до шести тикеров TQBR, например SBER, GAZP, LKOH. Выберите дневные/часовые свечи; для своего диапазона включите «Свои даты». Нажмите «Загрузить MOEX».
3. Во вкладке «Исследования и выпуск» проверьте готовность данных. Кнопки маршрута ведут к данным, качеству, правилам, бэктесту, устойчивости и виртуальному счёту. Обычный режим скрывает экспертные лаги и подробную таблицу индикаторов.
4. Загрузите текущие лот и шаг из MOEX. Они подставятся для выбранной акции. Для неизвестной бумаги расчёт MOEX блокируется до загрузки метаданных либо явной ручной проверки. В ручном режиме вы отвечаете за значения лота и шага. Нулевой шаг разрешён для ДЕМО/явного ручного допущения.
5. Настройте правила и риск, нажмите общий расчёт. Он работает в фоне; изменение настроек отменяет применение устаревшего результата. Результаты на экране могут относиться к предыдущему запуску, пока новый не завершён.
6. Сравните базовые стратегии, walk-forward, соседние настройки и стресс. Только после этого отдельно откройте финальные 20% истории. Повторный просмотр больше не считается независимой проверкой.

## Исполнение и риск

Сессионная дата рассчитывается с историческим смещением Europe/Moscow на начало свечи (в том числе UTC+4 до реформы 2014 года), а не с фиксированным современным UTC+3. Смещение входит в сохранённые свечи и их SHA-256; старые записи из семи полей получают его по временной зоне при чтении.

Покупка округляется вверх по MINSTEP, продажа вниз. Объём — целое число лотов. Денег должно хватить на покупку вместе с комиссией. При стопе модельный риск одной акции:

`цена_покупки − ожидаемая_цена_выхода_по_стопу + rate × (цена_покупки + ожидаемая_цена_выхода_по_стопу)`.

Из бюджета `капитал × риск` сначала вычитаются две фиксированные комиссии. Затем берётся минимум ограничений риска, доли капитала, денег, предыдущего объёма и технической границы количества. Стоп не гарантирует цену; при гэпе выход происходит по доступному открытию и может потерять больше бюджета. Спред/проскальзывание и округление учитываются в капитале один раз; отдельная сумма издержек показывается справочно.

Новые закрытые свечи — **задержанная ретроспективная симуляция**, а не исполнение по доступной сейчас рыночной цене. Публичная свеча может позднее исправляться источником; уже обработанная свеча не переисполняется. Лимиты риска работают по наблюдаемым закрытиям. Аварийный стоп запрещает новые входы, а имеющаяся позиция закрывается при следующей доступной свече по той же модели. При отсутствии данных позиция не исчезает.

## Приватность и ресурсы

- Нет брокерских торговых API, обязательной регистрации, телеметрии и автоматической проверки обновлений. Публичные HTTP-запросы получают только известные официальные адреса; TLS не отключается, перенаправления/ответы ограничены транспортом.
- Автоматически сохраняются только прежние безопасные настройки интерфейса; котировки и капитал — только при явном локальном экспорте. Сетевые токены не участвуют ни в проекте, ни в отчёте. Не отправляйте экспорт третьим лицам, если не хотите раскрыть свои параметры виртуального счёта.
- Проект ограничен 8 MiB, шестью сериями по 5000 свечей. Проверяются формат, версия, диапазоны и OHLC/время. Данные из файла всегда помечены как локальный источник без повторной онлайн-проверки. Файл не содержит выполняемого кода/произвольного сетевого адреса.
- Вычислительный запуск один, экспорт один; тяжёлые исследования/экспорт выполняются в фоне. Результаты устаревшего или отменённого расчёта не применяются. Последние 10 сравнений, 500 строк GUI-журнала, 10000 событий движка; память и сетевые страницы ограничены.
- «Очистить данные» удаляет состояние лаборатории, кэши, проекты в RAM, виртуальный капитал/счёт и сравнения. Уже сохранённые пользователем файлы на диске автоматически не удаляются.

## Проверка

Численные эталоны предыдущей версии сохраняются. Добавлены проверки полного риска с издержками/шагом, задержки исполнения и аварийного выхода, отсутствия влияния будущих цен на выбор параметров holdout, эмбарго, сетки/стресса на 5000 свечей, десятистраничной загрузки, отмены и сервера, игнорирующего пагинацию. GUI-тест проверяет конфигурацию, отклонение неверных значений, безопасные настройки сохранения, восстановление архивного счёта, HTML и PDF в рабочем потоке. Выпуск проверяется в Windows/Linux CI и Linux ASan/UBSan; конкретный результат см. Actions соответствующего commit.

Полные формулы аналитики, прежний конструктор и методологические ограничения: [LAB_GUIDE_RU.md](LAB_GUIDE_RU.md). Сборка с исходников: [GUIDE_WINDOWS_RU.md](GUIDE_WINDOWS_RU.md).

Официальные источники: [MOEX ISS](https://www.moex.com/a8531), [справочник](https://iss.moex.com/iss/reference/), [Qt QPdfWriter](https://doc.qt.io/qt-6/qpdfwriter.html). Наличие метода/HTTP 200 не гарантирует доступность конкретного набора данных без подписки.
