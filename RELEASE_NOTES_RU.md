# Quant Price Live 6.1.0

Этот выпуск объединяет накопленные изменения исследовательской платформы в основной ветке `main`.

## Что доступно

- Российские акции через официальный публичный MOEX ISS без обязательной регистрации; отдельное явно синтетическое ДЕМО.
- Количественная аналитика закрытых свечей, контроль качества, сравнение рядов и виртуальные стратегии с издержками и риском.
- Объяснение сигналов, история экспериментов и проверяемые снимки расчётов.
- Три автономных учебных задания: комиссии, риск гэпа и переобучение.
- Портфель до шести акций: общий капитал, целевые доли/SMA/RSI, ребалансировка, вклад инструментов и базы сравнения.
- Пошаговый тренажёр и новые закрытые свечи MOEX с согласованием потоков, паузой, защитой от дублей и аварийным стопом.
- `.qpp.json` для входного проекта; `.qpa.json` для сохранения и проверяемого восстановления состояния счёта. Открытие файла не подключает сеть.

## Установка и обновление

1. Скачайте **QuantPriceLive-6.1.0-Windows-x64.zip** из Assets этого выпуска. Source code — исходники для сборки, а не готовая программа.
2. Распакуйте весь ZIP в отдельную новую папку. Запускайте `START_QUANT_PRICE_LIVE.cmd`; начальная инструкция — `START_HERE.html`.
3. Если Windows сообщает об отсутствии MSVCP140/VCRUNTIME140, установите официальный [Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).
4. Пользовательские проекты и счета храните отдельно от папки программы. Состояние активного счёта сохраняйте по кнопке до закрытия; автоматического сохранения и обновления приложения нет.

Актуальный подробный русский гайд входит в ZIP: `WORKBENCH_GUIDE.html` и `WORKBENCH_GUIDE_RU.md`. Для будущих обновлений используйте [последний выпуск](https://github.com/Archibald02/Vega-C-Novikov/releases/latest).

## Проверки и ограничения

Выпуск публикуется после Windows/Linux CTest, визуальных GUI-проверок, ASan/UBSan, проверки упакованного Windows-приложения и документации. Перед публикацией ZIP проверяется по `VERSION.json` и всем внутренним SHA-256, затем скачивается из черновика Releases и проверяется повторно. SHA-256 всего ZIP опубликован отдельным файлом; он выявляет повреждение и не является цифровой подписью разработчика.

Программа учебная: данные MOEX задержаны, сделки виртуальные и ретроспективные. Реальных поручений нет. Дивиденды/сплиты и биржевая очередь в портфельной модели не учитываются. Сетевое продолжение восстановленного счёта требует отдельного подтверждения параметров. Этот выпуск не означает завершение всех направлений `ROADMAP_RU.md`.
