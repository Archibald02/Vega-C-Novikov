## Нагрузка и границы проверки

В 150-секундном прогоне Qt offscreen после первого отсчёта: CPU 1,0–2,3% одного ядра, RAM всего процесса 47,4–49,4 МиБ; после заполнения 10 000 точек RAM оставалась 49,4 МиБ. История заранее выделена: 0,69 МиБ. За прогон около 299 пересозданий кэша графика при лимите 2 кадра/с. Это замер Linux на данной машине, не обещание одинаковых цифр на Windows, HiDPI или ином потоке. Это не многосуточный прогон. Сравнение скорости с предыдущей версией в одинаковых условиях не проводилось.

ASan/UBSan ищут ошибки адресации и неопределённое поведение в исполняемых сценариях. LeakSanitizer отключён (detect_leaks=0), поэтому это не полная проверка утечек Qt и драйверов. Отдельно проверены границы буферов, число оставшихся запросов и стабильность RAM после заполнения истории. Тесты не доказывают отсутствие всех возможных ошибок.

## Как повторить

```
ctest --test-dir build -C Release --output-on-failure
quant_price_live --visuals-test
quant_price_live --privacy-test
quant_price_live --stress-test
quant_price_live --soak-test
quant_price_live --check-catalog
quant_price_live --check-moex
quant_price_live --check-history
```

`--soak-test` длится 150 секунд и проверяет заполнение истории. Для Linux без дисплея задайте QT_QPA_PLATFORM=offscreen. Тест приватности использует отдельную временную папку настроек и синтетические секреты.

Windows и Linux, Linux ASan/UBSan, пакет с DLL и публикация документации проверяются в [GitHub Actions](https://github.com/Archibald02/Vega-C-Novikov/actions). Windows-пакет проходит GUI visuals и privacy tests с изолированным PATH. Результат актуального запуска проверяется по commit SHA.

Реальный АЛОР с пользовательским токеном не проверялся. Базовый учебный сценарий использует публичный MOEX без аккаунта. Правила бесплатного доступа и наличие данных контролируются источником; сетевое обновление не устраняет задержку биржевых данных.
