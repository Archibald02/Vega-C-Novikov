# Проверка комплекта v2

Проверено 27 октября 2026 в Linux: GCC 13.3, Qt 6.8.3, Release.

- CMake-сборка приложения, численной библиотеки, тестов и benchmark успешна.
- doctest: 11 сценариев, 30 062 assertions, все успешны. Из них 30 000 примерно
  приходятся на последовательную сверку скользящего окна с пакетным эталоном.
- CTest: 3/3 — численные тесты, API payload tests и автономный запуск GUI.
- GUI отрендерен и визуально проверен: таблица четырёх тикеров и график помещаются.
- MOEX online check получил реальные ответы SBER и GAZP внутри приложения.
  Данные этого публичного источника имеют задержку; проверка не подтверждает real-time.
- Google Benchmark: 8 результатов сформированы в JSON.
- Doxygen 1.14.0 создал HTML без ошибок и предупреждений.
- YAML workflow разобран локально; это не заменяет реальный запуск GitHub Actions.

АЛОР реализован по официальному протоколу. Разбор сообщений проверен unit-тестами;
реальная авторизация, права токена и поток на пользовательском аккаунте здесь НЕ
проверялись: пользовательского токена нет. Ошибки сети/восстановление реализованы,
но полный интеграционный сценарий с реальным АЛОР не пройден.
Windows-сборка, windeployqt и публикация Pages здесь не запускались. Их нужно
проверить в вашем GitHub. В архиве исходников готового Windows EXE нет.

Локальная CMake-сборка использовала FETCHCONTENT_SOURCE_DIR для оригинальных
исходников doctest/benchmark, заранее скачанных из их репозиториев. Qt установлен
из официальных бинарных пакетов. Для OpenGL использованы установленные системные
библиотеки и заголовки пакета libgl-dev. Это настройки среды проверки; в исходники
они не внесены. Обычная сборка скачивает библиотеки через FetchContent.
