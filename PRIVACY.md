# Данные и приватность — Quant Price Live 6

## Явные локальные экспорты версии 6

По умолчанию котировки, виртуальный капитал и журналы не записываются. «Сохранить проект» сохраняет настройки; отдельные выключенные флажки разрешают капитал и котировки/архивный счёт. «Отчёт HTML/PDF» явно сохраняет результат с выбранным капиталом и сделками по выбранному пользователем пути. Сетевые токены/логины/заголовки туда не попадают. Очистка состояния приложения не удаляет уже экспортированные пользователем файлы.

Режим новых закрытых свечей опрашивает публичный ISS раз в минуту. Проверка последнего GitHub Release выполняется только по кнопке и не скачивает/устанавливает программу. Серверы MOEX/GitHub видят обычные данные сетевого соединения; приложение не добавляет персональные идентификаторы.

Ограничения ниже о хранении только в RAM относятся к автоматическому поведению, без явно запрошенных пользователем экспортов версии 6.

## Для основного режима регистрация не нужна

Публичный MOEX ISS: каталог TQBR, пакет котировок выбранных тикеров и свечи OHLCV. Используются официальные JSON API по HTTPS, без скрейпинга страниц, обхода доступа и сторонних прокси. Сервер может ограничить публичные данные; приложение показывает ошибку без предложения вводить пароль. Публичные цены задержаны. Данные не корректируются приложением на дивиденды/сплиты.

## Какие запросы отправляются

| Получатель | Зачем | Что передаётся |
|---|---|---|
| iss.moex.com | Каталог, выбранные котировки и свечи | Тикеры, TQBR, период/интервал; IP и обычные сетевые метаданные доступны серверу |
| oauth.alor.ru | Только при ручном выборе АЛОР и подключении | Введённый Refresh token в JSON-теле HTTPS POST |
| api.alor.ru | Только дополнительный АЛОР WebSocket | Access token и тикеры в защищённой подписке на котировки |
| Официальные сайты из вкладки помощи | Только по нажатию ссылки | Ссылка открывается внешним браузером; его сессия/настройки регулируются самим браузером |

В приложении нет встроенного входа в GitHub, почту или другие сервисы. Брокерские логины, пароли, ФИО, номер счёта, портфель, ордера и сделки пользователя не запрашиваются. Нет телеметрии, рекламы и сервера разработчика. Нет отправки торговых поручений.

## Что сохраняется

Сохраняются только настройки: тикеры, расчётное окно, интервал потока, выбранный источник, режим перерисовки, лимит точек и период опроса ISS. При запуске источник всегда MOEX без авторизации. На Windows Qt QSettings обычно использует `HKEY_CURRENT_USER\Software\QuantPriceLab\QuantPriceLive`; в Linux — пользовательский конфигурационный файл Qt.

Токен, котировки, свечи, сумма капитала, стоп/цель, прогнозы и ценовые пороги на диск приложением не записываются. Автоматический HTTP-кэш не используется. Явный локальный кэш публичной истории описан ниже; по умолчанию он выключен. Токен не читается автоматически из окружения. После отключения, ошибки авторизации или смены источника поле очищается. Оперативная память процесса и действия ОС не являются гарантированным защищённым хранилищем: поэтому для учебного сценария используйте режим без токена.

Кнопка «Отключиться и очистить настройки / данные сессии» отменяет запросы свечей, останавливает поток, удаляет ключи QSettings и очищает введённые секреты/цены/расчёты интерфейса. Публичный справочник инструментов не является пользовательским профилем.

## Ограничения транспорта

HTTP не следует перенаправлениям, не загружает/не сохраняет cookies и не переиспользует HTTP-авторизацию. TLS проверяется Qt без отключения проверки сертификатов. Ответы ограничены по размеру и общему времени; закрытие контекста отменяет запрос. В ошибках не показываются сырые ответы сервера или токены. HTTP 429 учитывает Retry-After (до 300 секунд), опрос котировок имеет backoff. Запросы не идут параллельно внутри одного источника; каталог и свечи загружаются отдельно по явному действию.

Это описание реализации и проверок, а не сертификация соответствия законодательству. Проверки перечислены в VERIFICATION.md.

Официальные сведения: https://www.moex.com/a8531 ; https://alor.dev/docs/api/usage/data


## Лаборатория версии 5

Лаборатория использует тот же официальный MOEX endpoint свечей. Виртуальный счёт, капитал, параметры правил, результаты, журнал и статистические ряды остаются в оперативной памяти. Они не добавлены в QSettings, файлы или телеметрию. Нет вызовов API портфеля или отправки поручений. Общая очистка отменяет применение фоновых результатов, очищает лабораторию и виртуальный счёт; торговые параметры по умолчанию не являются рекомендацией.

## RAM-менеджер истории

До восьми наборов свечей и одна контрольная точка незавершённого запроса хранятся только в памяти. Этот RAM-режим не использует файловый кэш, cookies, токены, логины, сырые ответы API или телеметрию. Необязательный дисковый режим включается отдельно. Продолжение пользователь запускает явно; перед ним проверяется последняя принятая страница. Открытие набора из RAM не обращается к сети. Источник и время повторно использованных данных видны в контексте/отчёте. Общая очистка приватных данных удаляет наборы, точку и их сведения, а также подавляет поздние сетевые ответы. Пауза ограничения API сохраняется, чтобы очистка не обходила Retry-After.

Догрузка правой границы использует выбранную базу только в RAM. Незавершённая операция/контрольная точка может удерживать её копию по общему пределу 5000 свечей, чтобы не зависеть от вытеснения кэша. Общая очистка удаляет кэш, текущую операцию, точку и удерживаемую базу. Ранние данные не перепроверяются автоматически, их повторное использование отмечено в источнике. Нет новых аккаунтов, дисковых файлов или фоновых периодических запросов.

Догрузка начала (6.11) также запускается только кнопкой и использует тот же публичный MOEX endpoint. Поздняя часть и удерживаемая контрольной точкой база остаются в RAM, без нового файлового хранения, токенов или телеметрии. Общая очистка отменяет запрос и удаляет базу; частичные ранние свечи не публикуются как готовый набор.

Перепроверка участка (6.12) передаёт ISS выбранные даты с опорными днями, тикер и интервал только по кнопке. Результаты и удерживаемая база остаются в RAM; новых настроек QSettings, файлов, учётных записей и телеметрии нет. Общая очистка удаляет контрольную точку и её базу.

Архив 6.13 дополнительно удерживает до восьми прежних публичных серий ×5000 свечей, не более двух разных содержимых на ключ. Диска, QSettings, телеметрии и новых сетевых запросов при открытии архива нет. Родительский ключ и архив вытесняются вместе. Выборочное удаление/очистка архива не стирает уже показанное исследование; общая очистка приватных данных удаляет все наборы/архив/контрольную точку, очищает результаты и подавляет поздние ответы. Явный экспорт открытого исследования по-прежнему отдельное действие пользователя.


## Необязательный дисковый кэш истории (в разработке)

Выключен при каждом запуске, не сохраняется в QSettings/проекте. До включения папка не читается и не создаётся. После включения список читается локально, а свечи записываются только отдельной кнопкой пользователя. Папка показана в интерфейсе: `history-cache` в стандартном пользовательском каталоге данных Quant Price Live.

В файлах находятся тикер, запрошенный период/интервал, принятые OHLCV и время начала/завершения загрузки, признаки частичной проверки/лимита и SHA-256. Нет токенов, заголовков, капитала, сделок и сырых сетевых ответов. Лимит — восемь файлов до 1 МиБ, общий настраиваемый объём 1–8 МиБ; во время атомарной записи один временный файл может занимать дополнительно до 1 МиБ. Сохраняется последний выбранный вариант ключа, не вся история редакций.

Открытие без HTTP не подтверждает актуальность и происхождение; данные помечаются «ДИСК», не переводятся в свежий сетевой кэш и не подключают виртуальный счёт. Выключение оставляет сохранённые файлы. Кнопка очистки кэша удаляет только принадлежащие этому кэшу JSON-файлы; общая очистка приватных данных также отключает режим и ставит удаление после текущей операции. Поздний результат чтения не восстанавливает очищенное исследование. Явно экспортированные пользователем проекты/отчёты по-прежнему не удаляются.

Операции выполняются в фоне с отменой и блокировкой между процессами. Целостность отдельной записи проверяется; это не криптографическое подтверждение источника. При ошибке или отмене многофайлового вытеснения уже удалённые записи не восстанавливаются. Обычные GUI-тесты используют отдельную временную папку и не обращаются к пользовательскому кэшу.
