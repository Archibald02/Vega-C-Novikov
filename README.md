# Quant Price Live 6.1

Нативное приложение на **C++17 и Qt 6** для мониторинга российских акций:
таблица котировок, график, SMA, разброс доходностей и настройки подключения.
Основной сценарий не использует CSV. Данные поступают из интернета асинхронно.

**Документация Doxygen:** https://archibald02.github.io/Vega-C-Novikov/

Репозиторий: https://github.com/Archibald02/Vega-C-Novikov

## Интерфейс 6.1

Стартовый экран с выбором задачи; отдельные котировки и исследование; последовательные шаги слева и понятное следующее действие. Источник, акция и фактические даты видны постоянно. Есть готовые правила стратегии, краткие карточки результата, раскрываемые подробности и словарь терминов. Изменённый набор/устаревший результат явно отмечаются. Экспертные параметры скрыты по умолчанию, колесо мыши не меняет поля без фокуса.

Первое знакомство: **Начало → Открыть учебное ДЕМО → Проверить данные → Анализ → Стратегия → Рассчитать и открыть результат**. [Подробный маршрут](WORKBENCH_GUIDE_RU.md).

## Новое в версии 6 — устойчивость и рабочие исследования

Все 15 направлений: лот/шаг из MOEX, риск с издержками, история до 5000 свечей с датами/пагинацией, проверка готовности, связанные графики и отметки сделок, маршрут исследования, локальные проекты, сравнение запусков, карта параметров, финальный holdout, стресс-сценарии, новые закрытые свечи для виртуального счёта, HTML/PDF и проверяемый Windows-пакет.

Календарная сверка использует наблюдаемые сессии IMOEX; полный календарь исключений и доступность дивидендов/сплитов не гарантируются публичным API. Неизвестные события явно помечаются, цены автоматически не корректируются. Публичные свечи остаются задержанными.

Начните с [гайда версии 6](WORKBENCH_GUIDE_RU.md) (в Windows ZIP также `WORKBENCH_GUIDE.html`). После распаковки всего пакета можно использовать `START_QUANT_PRICE_LIVE.cmd`; версия и commit находятся в `VERSION.json`. Котировки/капитал сохраняются только по явному локальному экспорту, токены не сохраняются никогда.

## Новое в версии 5 — лаборатория

- Аналитика закрытых свечей: доходности, гистограмма, квантили, корреляции согласованных интервалов, ACF/PACF, ADF/KPSS, Z-score, SMA/EMA/RSI/MACD/Bollinger, ATR/NATR.
- Качество данных: отбраковка, календарные разрывы, возраст последнего закрытия, исключение незавершённых свечей; счётчики потока и сетевых ошибок.
- Конструктор: по два условия входа/выхода, И/ИЛИ, пороги и пересечения. Покупки без плеча, только виртуально.
- Бэктест: следующий open после сигнала close, комиссии/спред/проскальзывание, гэпы, два сценария стопа/цели, модель ликвидности по прошлому объёму.
- Walk-forward с ограниченной сеткой; кривые капитала/просадки, Sharpe/Sortino/Calmar, база удержания и денежная база.
- Виртуальный счёт для replay архива, журнал причин и лимиты риска. Реальных поручений и обязательной регистрации нет.
- Расчёты в фоновом потоке, ограниченная память, отмена устаревших заданий. Windows-пользователю не нужен Python.

Начать: **Начало → Открыть учебное ДЕМО → Анализ → Рассчитать**. Для рынка вместо ДЕМО загрузите до шести тикеров MOEX. Подробности и ограничения: [гайд лаборатории](LAB_GUIDE_RU.md), локально также LAB_GUIDE.html.

## Начните без регистрации

По умолчанию выбран публичный MOEX ISS. Логин, пароль и API-ключ не нужны. Откройте каталог, выберите акции и подключитесь. Во вкладке **Свечи MOEX** нажмите «Загрузить свечи без регистрации» для OHLCV и объёмов. Публичные котировки и свечи задержаны; наличие интернет-запросов не делает их real-time. Доступность публичных блоков определяет MOEX.

Сохранившиеся возможности:

- Настоящие свечи OHLCV, объёмы, SMA 20 свечей: дневные за 90/365 дней, часовые за 7 дней. Отдельный запрос по кнопке, до 5000 баров, отмена и ограниченный кэш RAM.
- Сравнение первых шести выбранных акций в процентах от первой сохранённой цены каждой; график учебной экстраполяции с наивной базой и прошлой ошибкой.
- Поле токена скрыто в основном режиме; при запуске всегда выбран источник без авторизации. Автоматического чтения токена из окружения нет.
- Сброс настроек и данных сессии; панели прокручиваются на небольшом экране.
- Общий HTTP-транспорт: абсолютный срок запроса, ограничение размера, отмена при закрытии, отказ от перенаправлений, cookies и повторного использования HTTP-авторизации. Ошибки/429 обрабатываются без ввода паролей.
- Автотесты сетевых отказов и жизненного цикла, 5000 повреждённых входов, 500 000 обновлений; ASan/UBSan в Linux.

[Какие данные используются и сохраняются](PRIVACY.md). [Проверки и ограничения](VERIFICATION.md).

## Источники

| Режим | Доступ | Характер данных |
|---|---|---|
| АЛОР | Боевой аккаунт и Refresh token | WebSocket-подписки на котировки MOEX/TQBR |
| MOEX ISS | Без ключа | Публичные данные с задержкой, HTTP раз в 5 секунд |
| ДЕМО | Без сети и аккаунта | Явно помеченные синтетические цены |

По FAQ АЛОР использование OpenAPI бесплатно. Для боевого потока нужен именно
торговый аккаунт, не только учётная запись разработчика. Условия обслуживания
счёта проверяются отдельно. Тестовый контур АЛОР не является источником реальных котировок
и в этой версии не подключается. Проект не размещает торговые поручения.

## Возможности версии 4

- Каталог доступных акций MOEX TQBR: поиск по тикеру/названию, выбор до 20 акций, размеры лотов. Каталог загружается по запросу и кэшируется на 15 минут.
- Кнопки перехода на получение токена АЛОР, инструкции API и MOEX ISS.
- Таблица last/bid/ask, спред в базисных пунктах, изменение дня и возраст ответа.
- График с масштабированием колесом и курсором; SMA, EMA, Bollinger 20/2; RSI 14 и MACD 12/26/9.
- Учебные прогнозы: линейный тренд и последняя цена, последовательная ретропроверка, сравнение MAE. По умолчанию выключены.
- Калькулятор длинной позиции без плеча по капиталу, риску и размеру лота; одноразовые ценовые пороги внутри окна.
- Вкладка производительности: 2/4/10 обновлений интерфейса в секунду, 500/2000/5000 точек на акцию, опрос ISS раз в 5–60 секунд.
- Потоковые индикаторы O(1), заранее выделенные кольцевые буферы; график кэшируется и обновляется по изменениям. Во время простоя периодической перерисовки нет.
- Один пакетный HTTP-запрос ISS на все выбранные акции. Ограничены размер ответа, тайм-аут и число одновременных запросов.
- Внизу окна: CPU процесса, RAM, число точек, размер буферов и счётчик перерисовок. Сохранение настроек без токена и котировок.

Индикаторы вычисляются по **принятым обновлениям цены**, а не по биржевым свечам. Горизонт прогноза измеряется числом обновлений. MAE на прошлых данных не обещает точность в будущем; коридор ±2 RMSE — эвристика, не доверительный интервал. Калькулятор не учитывает комиссии, гэпы и проскальзывание, а порог в приложении не является биржевой стоп-заявкой.

Нет предварительной загрузки истории: график заполняется с момента подключения.
Первая цена появляется после ответа источника; мгновенность и задержка сети не гарантируются.
Подписка АЛОР передаёт агрегированные обновления котировок, не каждую сделку.
Параметр «Поток» — интервал выдачи сообщений, а не полная задержка от биржи до экрана.

## Быстрый запуск Windows без установки компилятора

1. Откройте вкладку Actions этого репозитория.
2. Дождитесь успешного workflow в Actions.
3. В Artifacts скачайте **QuantPriceLive-Windows-x64**.
4. Полностью распакуйте ZIP, оставив DLL и подпапки рядом с EXE.
5. Запустите **quant_price_live.exe**.

На чистом компьютере может потребоваться официальный Microsoft Visual C++ Redistributable x64:
https://aka.ms/vs/17/release/vc_redist.x64.exe

Windows EXE создаётся в вашем CI. В архиве исходников нет заранее собранного Windows EXE.
Пошаговая настройка репозитория и приложения — в START_HERE.html / GUIDE_WINDOWS_RU.md.

## Локальная сборка Windows

Нужны Git, CMake 3.20+, MSVC 2022 и Qt 6.8.3 **MSVC 2022 64-bit** с модулем Qt WebSockets.
Qt можно поставить через aqtinstall, подробности в гайде. В Developer PowerShell for VS 2022:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="C:/Qt/6.8.3/msvc2022_64"
cmake --build build --config Release --parallel 2
$env:PATH = "C:\Qt\6.8.3\msvc2022_64\bin;" + $env:PATH
ctest --test-dir build -C Release --output-on-failure
.\build\Release\quant_price_live.exe
.\build\Release\quant_benchmark.exe --benchmark_min_time=0.1s
```

CMake сам скачает doctest 2.4.12 и Google Benchmark 1.9.4. Нужен интернет при первой конфигурации.
Для папки запуска, независимой от Qt в PATH, используйте windeployqt (см. гайд).

## Linux

## Тесты и CI/CD

CI проверяет 11 групп тестов в Windows и Linux, doctest для формул и окон,
разбор сообщений API, сетевые сбои, cookies/redirects, очистку настроек, автономный GUI и bounded-history stress. Linux также запускает ASan/UBSan. Сетевые запросы и токены для тестов не нужны.
Benchmark измеряет пакетные функции и отдельное обновление скользящего окна;
13 результатов видны в логах, JSON — в artifacts. Единицы benchmark указаны в таблице.
Doxygen генерирует HTML и публикует его на Pages после успешной сборки.
Windows CI упаковывает приложение вместе с Qt DLL и проверяет запуск пакета.

## Метрики

SMA во время прогрева использует имеющиеся цены; карточка показывает N / размер окна.
σ — стандартное отклонение доходностей между принятыми обновлениями, в процентах.
Это **не годовая волатильность**: интервалы между сообщениями не фиксированы.
Указанное время АЛОР относится к последней сделке; время ISS — к снимку ответа сервера.
Старые ответы отбрасываются, одинаковые цена+время не дублируются в статистике.
Bid/ask могут обновляться без новой точки последней цены.

Токен вводится только вручную в локальное окно дополнительного режима АЛОР. Переменная окружения ALOR_REFRESH_TOKEN больше не считывается автоматически.
Его не надо добавлять в исходники, GitHub Secrets для CI или присылать в чат.
Функции отправки заявок и операций со счётом в программе отсутствуют.
