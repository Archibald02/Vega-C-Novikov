# План развития после 6.1

Все направления согласованы пользователем. План не является списком уже реализованных функций. Выпуски следуют по зависимостям, номера версий уточняются при упаковке.

| Направление | Ближайший результат | Проверка готовности | Состояние |
|---|---|---|---|
| Объяснение решений | Значения условий исходной стратегии на каждой свече | Прогрев, пересечения, неизменность после редактирования настроек; затем трассировка исполнения и риска | Разбор сигналов проверен Windows/Linux CI; трассировка исполнения запланирована |
| История экспериментов | Имена, гипотезы, сравнение настроек и воспроизводимый снимок | Точное повторение по сохранённым данным; экспорт только явно | Журнал результатов и сравнение реализуются; воспроизводимый снимок — следующий этап |
| Учебный режим | Автономные задания по комиссиям, риску и переобучению | Детерминированные примеры и объяснения результатов | Запланировано |
| Портфель | Общие деньги, позиции, ребалансировка и риск | Ручные эталоны общей бухгалтерии, одновременные сигналы, отсутствие будущих данных | Запланировано |
| Менеджер истории | Наборы, догрузка, возобновление, версии и необязательный дисковый кэш | Разрывы, исправления API, лимит диска, отмена и очистка | Запланировано |
| Корпоративные события | Дивиденды и дробления с происхождением данных | Проверка официального источника, даты доступности, отсутствие двойного учёта | Запланировано; зависит от доступности API |
| Конструктор | Группы условий, выдержка, паузы, выход по времени, частичные выходы и старший интервал | Совпадение объяснения и исполнения; только закрытые старшие свечи | Запланировано |
| Неопределённость | Блочный bootstrap, разные периоды и вклад отдельных сделок | Фиксируемый seed, корректные допущения, ограниченная нагрузка | Запланировано |
| Рабочее место | Темы, размер текста, поиск функций, шаблоны и колонки | Малый экран, клавиатура, HiDPI, сохранение безопасных настроек | Запланировано |
| Производительность | Кэш признаков, приоритеты задач, ресурсные профили | Измеренные CPU/RAM, ограниченная очередь, быстрый отклик отмены | Запланировано |
| Источники | Общий контракт каталогов, свечей, событий и состояния доступа | Контрактные тесты, задержка и происхождение видны, официальные адреса | Запланировано; новые провайдеры проверяются отдельно |
| Выпуски | GitHub Releases, portable/установщик, миграция проектов и диагностика | Чистая Windows, обновление старого проекта, просмотр диагностики до передачи | Запланировано |

Первые поставки: объяснение сигналов → сохранённые эксперименты → учебные примеры. Затем общий портфельный движок и расширенные правила, после них данные/события и масштабирование. Трассировка реального модельного исполнения дополняет объяснение условий отдельным этапом.

Общие требования: только виртуальные сделки; MOEX без обязательных аккаунтов; синтетические и задержанные данные явно отмечены; токены не записываются; локальный кэш и автосохранение включаются пользователем. Фоновая работа, ограниченная память и очереди, отмена, контроль численных эталонов. Для каждого опубликованного выпуска обязательны Windows/Linux CI, GUI, санитайзеры и проверка упакованного приложения.
